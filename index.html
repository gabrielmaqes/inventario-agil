Política de Privacidade — Inventário Ágil

Última atualização: 27 de outubro de 2026

O Inventário Ágil é um aplicativo de contagem de estoque que funciona inteiramente no seu aparelho.

Dados que coletamos

Nenhum. O aplicativo não tem cadastro, login, servidor, anúncios, análise de uso nem rastreamento de qualquer tipo.

Dados guardados no seu aparelho

Os produtos, etiquetas, inventários, quantidades e preferências que você registra ficam salvos apenas na memória do seu aparelho. Nós não temos acesso a eles. Eles são apagados quando você desinstala o aplicativo ou limpa os dados dele.

Câmera

A câmera é usada somente para ler códigos de barras, no próprio aparelho. Nenhuma foto ou vídeo é gravado ou enviado.

Arquivos

O aplicativo só lê um arquivo quando você escolhe importar produtos, e só cria um arquivo quando você escolhe exportar um inventário. Para onde esse arquivo vai depois (e-mail, mensagens, nuvem) é decisão sua, e segue a política do aplicativo que você escolher para compartilhar.

Crianças

O aplicativo não é direcionado a crianças e não coleta dados de ninguém, inclusive de crianças.

Alterações

Se esta política mudar, a nova versão será publicada nesta página com a data de atualização.
